# Mahashri English Vocabulary — WordWise

A personal English vocabulary learning portal built with plain HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a modern browser. No build step, server, API key, or external library is required.

## Features
- Vocabulary starter list based on everyday expressive words
- Today's words, search, categories, and sorting
- Mark words learned and favorite words
- Multiple-choice quiz and flashcards
- Speaking practice with saved example sentences
- Add your own vocabulary with definitions and examples
- Progress counters and daily learning goal
- Export your vocabulary and progress as a JSON backup
- Responsive layout and light/dark theme toggle

## Data and privacy
The portal saves your words and progress in browser localStorage on the current device/browser. Use **Export** regularly to back up your data. Clearing browser site data can remove locally stored progress.
