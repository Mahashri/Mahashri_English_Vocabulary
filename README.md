# Mahashri English Vocabulary — WordWise

A responsive English vocabulary learning portal built with plain HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a modern browser. No build step, server, API key, or external library is required.

## Features
- Mobile-responsive layout for phones, tablets, and desktops
- **Your Words**: original words and phrases you shared, highlighted with a teal border and a "YOUR WORD" label
- **More Everyday Words**: a separate collection of extra vocabulary
- Search across vocabulary, meanings, examples, and usage tips
- Category filters and A–Z / Z–A / learned / recently added sorting
- Shuffle collection order and choose 8, 12, 16, or 24 words per page
- Pagination
- Mark words learned and favorite words
- Flashcards and multiple-choice quizzes
- Speaking practice with saved example sentences
- Add custom vocabulary
- Progress counters and daily goal
- Export a JSON backup
- Light/dark theme toggle

## Data and privacy
Your words and progress are saved in browser localStorage on the current device/browser. Use **Export** regularly to back up your data. Clearing browser site data can remove locally stored progress.
